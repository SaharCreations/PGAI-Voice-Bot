# Architecture

The bot uses Telnyx Call Control to dial only the authorized assessment number and request a dual-channel MP3 recording. After answer, Telnyx opens an authenticated bidirectional media WebSocket to a FastAPI/asyncio application. Incoming 8 kHz PCMU audio is decoded and upsampled for Telnyx-hosted Deepgram Nova-3 streaming transcription. Final transcript fragments are combined into conversational turns and passed to Claude Haiku 4.5 with a scenario-specific patient prompt. Claude’s reply is synthesized using ElevenLabs Turbo v2.5 as telephony-native `ulaw_8000` audio, divided into 20 ms frames, paced back to Telnyx, and committed to conversation history only after Telnyx acknowledges the playback mark. Inbound speech can cancel generation, clear queued playback, and prevent interrupted replies from contaminating later context.

I chose a modular STT → LLM → TTS pipeline instead of an end-to-end realtime API because it provides direct control over patient behavior, multiple voices, mid-call identity changes, barge-in, and evidence provenance. The tradeoff was latency across three external services. I reduced it through 300 ms STT endpointing, a 250 ms fragment-only settle timer, immediate flushing of completed turns, persistent ElevenLabs connections, concise Claude output, and direct mu-law streaming. Signed Telnyx webhooks, one-use media tokens, strict call/session matching, atomic evidence writes, source hashes, dual-channel transcription, and cross-call audits make every reported result traceable to the submitted recordings.

After evidence is complete, an optional Claude evaluator can perform a preliminary review of one call or every scenario. It validates the MP3 and transcript hashes before analysis, requires every generated finding to reference a real transcript timestamp and verbatim quote, and writes isolated `analysis.json` and `analysis.md` artifacts. Automatic post-call execution is disabled by default to prevent unplanned API spend. These generated reports accelerate triage but never modify or replace the human-reviewed `BUG_REPORT.md`.
